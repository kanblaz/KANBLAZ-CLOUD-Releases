## Features / Funciones

Local profiles, updated layouts, Xbox Cloud Gaming, GeForce NOW and Amazon Luna service options. Individual control or Shared routing to all open game windows. Supported audio and screen alerts; recognition varies with clarity. Luna gameplay has not yet been verified end-to-end.

FREE: up to 2 profiles / hasta 2 perfiles. PRO: no artificial profile limit / sin límite artificial de perfiles. Practical capacity depends on the PC and gaming service.

PRO: USD 5/month, USD 20/6 months, USD 30/year. Recurring until canceled; confirm final amount in Stripe. Existing lifetime licenses remain valid. Games and gaming-service subscriptions are not included.

## Compatibility and security / Compatibilidad y seguridad

Requires .NET Framework 4.8, Microsoft Edge WebView2 Runtime and the matching Visual C++ runtime. The x86 build was tested as a 32-bit process on 64-bit Windows, not on native 32-bit Windows. Per-window audio capture requires Windows build 20348+ and is unavailable on standard 32-bit Windows 10; OCR/visual alerts are separate.

Executables are currently **unsigned**. Windows may display SmartScreen or antivirus warnings. **Do not disable Defender or add exclusions.** Verify the release checksums; a checksum is not a malware-safety guarantee.

Los ejecutables aún **no tienen firma digital**. Windows puede mostrar advertencias. **No desactives Defender ni agregues exclusiones.** Verifica los hashes publicados; un hash no garantiza ausencia de malware.
